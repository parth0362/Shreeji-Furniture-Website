# Shreeji Furniture

A modern and responsive business website developed for **Shreeji Furniture**, a furniture and interior contracting company.

The website is designed to showcase the company's furniture craftsmanship, interior solutions, services, and completed projects through a clean and premium digital experience.

## ✨ Features

- Modern and premium UI design
- Fully responsive across desktop, tablet, and mobile
- Smooth animations and page transitions
- Furniture and interior project showcase
- Services section
- About Shreeji Furniture
- Contact and inquiry options
- Optimized user experience
- Clean and maintainable code structure

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Modern responsive UI
- Component-based architecture

## 🏠 About Shreeji Furniture

Shreeji Furniture provides custom furniture and interior contracting solutions with a focus on quality craftsmanship, functionality, and modern design.

The website represents the brand digitally with a modern, elegant, and professional experience.
